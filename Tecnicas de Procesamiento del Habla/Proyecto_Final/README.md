# 🚀 Proyecto Final Integrador
El objetivo es crear un prototipo de soporte de tickets para una e-commerce. El fin del proyecto es optimizar el servicio de atención al cliente, automatizando la detección de quejas o consultas, y generar una respuesta automática inicial para disminuir el tiempo de respuesta.


# 🛠 Herramientas:
* Pandas
* Transformers - HuggingFace
* Gemini API
* Gradio
